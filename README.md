# Oliv3rmoon's Homebrew tap

```sh
brew install oliv3rmoon/tap/welp
brew install oliv3rmoon/tap/uhh
```

- [welp](https://github.com/Oliv3rmoon/welp): fixes the command you just typed wrong. A fast successor to thefuck.
- [uhh](https://github.com/Oliv3rmoon/uhh): explains a command flag by flag, from your own man pages. Offline explainshell for your terminal.
